# Tecrys releases

Downloads of **Tecrys**, a parametric 3D CAD program, for macOS (Apple Silicon, macOS 14+) and
Windows (x64 and ARM64), and the feeds its built-in updater reads.

- **Download**: see [Releases](../../releases). Mac: the `.dmg`; Windows: `windows-x64.exe`
  (most PCs) or `windows-arm64.exe` (ARM PCs).
- **First start**: Tecrys is not signed by Apple or Microsoft. On the Mac open System Settings ▸
  Privacy & Security ▸ Open Anyway; in Windows click More info ▸ Run anyway. Later versions arrive
  through *Check for Updates…* in the app and need no approval.
- **Source**: every release includes its `…-source.tar.gz`. Tecrys is free software under the
  GNU GPL version 3.

**Ideas and problems**: [open an issue](../../issues/new/choose) (Suggest a feature / Report a problem;
a free GitHub account is needed). In Tecrys: Help ▸ Suggest a Feature… / Report a Problem….

Tecrys PDM and Tecrys Vault have their own pages:
[tecrys-pdm-releases](https://github.com/jakpokcz/tecrys-pdm-releases),
[tecrys-vault-releases](https://github.com/jakpokcz/tecrys-vault-releases).

The `appcast-*.xml` files are the update feeds (signed with the Tecrys update key); don't edit them by hand.
